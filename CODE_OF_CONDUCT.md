# Code of Conduct

Project participation must remain respectful, technically focused, and safe.
Harassment, personal attacks, discrimination, threats, publication of private
information, and deliberately unsafe advice are not accepted.

Reports and reviews should address observable behaviour, reproducible evidence,
and the code rather than the person contributing it. Maintainers may edit,
hide, reject, or remove contributions that violate this policy and may restrict
repeat offenders from project spaces.

Do not publish credentials, private network identifiers, unredacted system
logs, or security-sensitive key material. Follow `SECURITY.md` for sensitive
reports.
